========================================
AAPANEL HOSTING SETUP GUIDE
========================================

IMPORTANT: Follow these steps to avoid "Failed to save API key" and "404 errors"

1. FILE PERMISSIONS (CRITICAL)
   After uploading files to aaPanel:
   
   a) Set folder permissions to 755:
      - Right-click the folder in File Manager
      - Set permissions to 755 (rwxr-xr-x)
   
   b) Set file permissions to 644:
      - Select all .php, .html, .txt files
      - Set permissions to 644 (rw-r--r--)
   
   c) Ensure these files are writable:
      - api_key.txt
      - redirect_url.txt  
      - bot_url.txt
      - admin_password.txt
      - visitors.json
   
   d) Fix ownership if needed (advanced):
      - If permission changes don't work, check file ownership
      - Files should be owned by web server user (www-data or apache)
      - Contact hosting support if ownership issues persist

2. APACHE CONFIGURATION (For Clean URLs)
   
   a) Enable required modules in aaPanel:
      - Website → Site → Settings → Apache Module
      - Enable mod_rewrite (required)
      - Enable mod_authz_core (Apache 2.4 compatibility)
      - Restart Apache
   
   b) Enable .htaccess support:
      - Website → Site → Configuration
      - Ensure "AllowOverride All" is set
      - Ensure "Options FollowSymLinks" is enabled
      - Save and restart Apache
   
   c) Check .htaccess permissions:
      - Ensure .htaccess file is uploaded
      - Set .htaccess permissions to 644

3. ALTERNATIVE FOR SHARED HOSTING
   
   If mod_rewrite doesn't work, use these direct URLs:
   - Admin panel: yourdomain.com/folder/index.html
   - Direct redirect: yourdomain.com/folder/redirect.php
   
4. TESTING
   
   a) Test admin login first:
      - Visit yourdomain.com/folder/index.html
      - Try saving API key
      - If it fails, check file permissions again
   
   b) Test clean URLs:
      - Copy the campaign link from admin panel
      - Visit it in browser
      - If 404 error, use redirect.php instead

5. SUBFOLDER INSTALLATION (If installing in a subfolder)
   
   If you install CleanTraffic in a subfolder (e.g., yourdomain.com/cleantraffic/):
   - Add "RewriteBase /cleantraffic/" to .htaccess (after line 170)
   - Replace "/cleantraffic/" with your actual folder path
   - This ensures clean URLs work properly in subfolders

6. TROUBLESHOOTING
   
   "Failed to save API key":
   - File permissions issue (check folder: 755, files: 644)
   - File ownership issue (contact hosting support)
   - Use aaPanel File Manager to set permissions
   
   "404 Error on campaign links":
   - mod_rewrite not enabled (enable in aaPanel Apache settings)
   - AllowOverride not set (enable in site configuration)
   - Subfolder issue (add RewriteBase if needed)
   - Fallback: Use yourdomain.com/folder/redirect.php directly

========================================
SUPPORT: If issues persist, contact your hosting provider about:
- PHP file write permissions
- Apache mod_rewrite module
