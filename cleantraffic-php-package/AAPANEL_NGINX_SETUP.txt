========================================
AAPANEL NGINX CONFIGURATION GUIDE
========================================

IMPORTANT: aaPanel uses Nginx, NOT Apache. The .htaccess file is ignored!

🚨 PROBLEM: "404 not found nginx" = Nginx doesn't read .htaccess files

✅ SOLUTION: Add Nginx rewrite rules manually

========================================
STEP-BY-STEP SETUP:
========================================

1. LOGIN TO AAPANEL
   - Go to your aaPanel dashboard
   - Navigate to "Website" → Your Domain

2. OPEN NGINX CONFIGURATION
   - Click "Configuration" → "Configuration File" 
   - OR click "Rewrite" tab

3. ADD THESE RULES:
   Copy and paste this into your Nginx config:

   # Clean URL routing for CleanTraffic
   location ~ ^/([A-Za-z0-9]{5,12})/?$ {
       try_files $uri $uri/ /r.php?id=$1;
   }

   # Allow access to essential files
   location ~ ^/(index\.html|redirect\.php|r\.php|admin_auth\.php|check_auth\.php|get_config\.php|update_config\.php|get_visitors\.php|test_api\.php)$ {
       try_files $uri =404;
   }

   # Block sensitive files
   location ~ \.(txt|json|log)$ {
       deny all;
   }

   location ~ ^/\. {
       deny all;
   }

   # Route everything else to redirect.php
   location / {
       try_files $uri $uri/ /redirect.php?$args;
   }

4. SAVE AND RELOAD
   - Click "Save"
   - Click "Reload Configuration" or restart Nginx

========================================
ALTERNATIVE QUICK TEST:
========================================

If the above is too complex, test this simple rule first:

location ~ ^/([A-Za-z0-9]{5,12})/?$ {
    rewrite ^/(.*)$ /r.php?id=$1 last;
}

========================================
TESTING:
========================================

1. Visit: yourdomain.com/33BQ03y98404
2. Should redirect properly (not 404)
3. Admin panel: yourdomain.com/index.html

========================================
TROUBLESHOOTING:
========================================

"Still getting 404":
- Rules not saved properly
- Nginx not reloaded
- Rules in wrong location block

"Admin panel not accessible":
- Add specific allow rule for index.html
- Check file permissions (644)

========================================
WHY THIS HAPPENS:
========================================

cPanel = Apache (reads .htaccess) ✅
aaPanel = Nginx (ignores .htaccess) ❌

Solution: Use Nginx rules instead of .htaccess
